# Dawid Salwecki — Personal Website

A static HTML website, ready to deploy on Vercel. No build command or framework required.

## Deploy with Vercel

1. Extract this ZIP.
2. In Vercel, choose **Add New → Project** and import a Git repository containing these files, or use Vercel CLI from this folder.
3. For a plain static site, leave the framework preset as **Other** and leave the build command empty.
4. Set the output directory to `.` if Vercel asks for one.
5. Deploy.

## Before publishing

- Replace `hello@example.com` in `index.html` with the correct email.
- Replace placeholder/contact and support links with your real links.
- Review the site text and creator details before making it public.
